## 4. 第一关 —— "数一数" 详细设计

### 4.1 核心玩法

画面中央**快速闪现** 1~5 个水果（随机位置、随机种类），玩家需要在**倒计时结束前**点选下方正确的数字按钮。答对加分，答错扣时间，连续答对有连击奖励。

### 4.2 游戏流程

```
开始界面 → 点击"开始" → 3秒倒计时 → 进入游戏循环:
  ┌─────────────────────────────────────┐
  │  1. 随机生成1~5个水果（带弹出动画）   │
  │  2. 水果在画面中央随机位置出现        │
  │  3. 倒计时开始（初始5秒，逐渐缩短）   │
  │  4. 玩家点击下方1~5的按钮             │
  │  5. 判断对错 → 反馈 → 下一题          │
  └─────────────────────────────────────┘
  30秒后 → 游戏结束 → 显示成绩单
```

### 4.3 难度递进系统

| 阶段 | 时间范围 | 每题限时 | 水果数量 | 特殊规则 |
|------|----------|----------|----------|----------|
| 入门 | 0-10秒 | 5秒 | 1~3个 | 数量少，颜色区分明显 |
| 进阶 | 10-20秒 | 4秒 | 2~4个 | 水果出现后缩放抖动 |
| 挑战 | 20-30秒 | 3秒 | 3~5个 | 可能出现相同水果干扰 |

### 4.4 计分规则

| 行为 | 分数 |
|------|------|
| 答对（基础） | +10 分 |
| 答对（<1秒内） | +20 分（闪电奖励） |
| 连续答对3次 | +15 分（连击奖励） |
| 连续答对5次 | +25 分（超级连击） |
| 答错 | -5 分 + 剩余时间 -1秒 |
| 超时 | 0 分，进入下一题 |

### 4.5 视觉设计

#### 场景布局
```
┌────────────────────────────────────┐
│  分数: 120    连击: 3    时间: 18s  │  ← 顶部信息栏
│                                    │
│        🍎   🍌   🍇               │  ← 水果出现区域
│            🍊                      │     (画面中央偏上)
│                                    │
│  ┌───┬───┬───┬───┬───┐            │
│  │ 1 │ 2 │ 3 │ 4 │ 5 │            │  ← 数字按钮
│  └───┴───┴───┴───┴───┘            │     (画面下方)
└────────────────────────────────────┘
```

#### 水果出现动画
- **弹出效果**：从 0 缩放到 1.2 再回弹到 1.0（弹性动画，0.3秒）
- **随机旋转**：±15度随机倾斜，增加活泼感
- **随机大小**：基础尺寸的 80%~120% 变化
- **出现音效**：`jump.wav`

#### 数字按钮样式
- 大圆形按钮，每个数字一个醒目颜色
- 颜色方案：1=红, 2=蓝, 3=绿, 4=橙, 5=紫
- 按下时缩放 0.9 + 音效 `select-menu-select.wav`

#### 反馈效果
- **答对**：水果飞散 + 绿色勾 + `powerup-get-something-big.wav`
- **答错**：红色叉晃动 + `elect-menu-go-back.wav`
- **连击**：数字放大弹跳 + 彩色粒子

### 4.6 倒计时与时间系统

- **总游戏时间**：30秒（可设置）
- **每题限时**：根据难度阶段递减（5→4→3秒）
- **时间显示**：顶部圆形进度条 + 数字倒计时
- **时间耗尽**：自动跳到下一题，不扣分

## 5. 技术架构

### 5.1 目录结构

```
assets/
├── scenes/
│   └── Game.scene              # 主游戏场景
├── scripts/
│   ├── GameManager.ts          # 游戏主控制器
│   ├── FruitSpawner.ts         # 水果生成器
│   ├── TimerManager.ts         # 计时管理
│   ├── ScoreManager.ts         # 计分系统
│   ├── ButtonPanel.ts          # 数字按钮面板
│   ├── ResultPanel.ts          # 结算界面
│   └── AudioManager.ts         # 音效管理
├── prefabs/
│   ├── FruitItem.prefab        # 水果预制体
│   └── NumberButton.prefab     # 数字按钮预制体
└── resources/                  # (已有)
    ├── audio/                  # 音效
    └── images/                 # 水果图片
```

### 5.2 核心脚本职责

| 脚本 | 职责 |
|------|------|
| `GameManager` | 游戏状态机(开始/游戏中/结算)、难度控制、流程调度 |
| `FruitSpawner` | 随机生成水果、控制出现动画、管理水果池 |
| `TimerManager` | 总倒计时、每题倒计时、时间显示 |
| `ScoreManager` | 计分、连击统计、评级计算 |
| `ButtonPanel` | 5个数字按钮的输入处理、视觉反馈 |
| `ResultPanel` | 结算数据展示、重玩/返回按钮 |
| `AudioManager` | 单例，统一管理音效播放 |

### 5.3 关键实现要点

1. **对象池**：水果使用对象池管理，避免频繁创建销毁
2. **随机不重复**：同一题内水果位置不重叠（碰撞检测或网格分布）
3. **触控优化**：按钮尺寸 >= 80px，间距充分，防止误触
4. **性能**：限制同屏水果数 <= 5，使用 SpriteFrame 缓存

## 7. 开发步骤（按顺序）

1. **创建场景和基础UI** — Game.scene + Canvas 布局

5. **实现核心游戏循环** — GameManager 状态机
6. **实现计分系统** — ScoreManager + 连击逻辑
7. **实现计时系统** — TimerManager + 倒计时显示
8. **实现结算界面** — ResultPanel + 评级
9. **难度递进** — 根据时间自动提升难度
10. **打磨细节** — 动画、特效、音效串联
