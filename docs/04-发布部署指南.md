# 数一数 — 发布部署指南

## 1. 发布平台对比

| 平台 | 优势 | 劣势 | 适合阶段 |
|------|------|------|----------|
| **Web H5** | 零门槛、快速测试 | 性能一般、无原生功能 | 开发测试 |
| **微信小游戏** | 扫码即玩、传播方便 | 需审核、有包体限制 | 首次发布 |
| **抖音小游戏** | 流量大、推荐机制 | 审核严格 | 后续扩展 |
| **Android APK** | 性能好、功能完整 | 需安装 | 后续扩展 |

## 2. Web H5 构建（推荐用于测试）

### 2.1 构建步骤
1. Cocos Creator → `项目 > 构建发布`
2. 选择平台: `Web Mobile`
3. 配置:
   - `标题`: 数一数
   - `启动场景`: Start
   - `调试模式`: 勾选（开发阶段）
4. 点击 `构建`
5. 构建完成后点击 `运行`

### 2.2 本地测试
- 构建后会自动打开浏览器
- 或手动访问: `http://localhost:7456/build/web-mobile/`

### 2.3 手机测试
1. 确保手机和电脑在同一局域网
2. 查看电脑IP地址（命令行输入 `ipconfig`）
3. 手机浏览器访问: `http://<电脑IP>:7456/build/web-mobile/`

### 2.4 部署到服务器
1. 将 `build/web-mobile/` 目录上传到 Web 服务器
2. 访问对应域名即可

## 3. 微信小游戏构建

### 3.1 前置准备
1. 注册微信小程序账号: https://mp.weixin.qq.com/
2. 下载微信开发者工具: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. 获取 AppID（在小程序后台 > 开发 > 开发管理）

### 3.2 构建步骤
1. Cocos Creator → `项目 > 构建发布`
2. 选择平台: `WeChat Mini Game`
3. 配置:
   - `AppID`: 填入你的 AppID（或使用测试号）
   - `启动场景`: Start
   - `远程服务器地址`: 如果有资源服务器，填入地址
4. 点击 `构建`

### 3.3 微信开发者工具导入
1. 打开微信开发者工具
2. 选择 `小程序项目`
3. 项目目录: `C:\Dev\NumberGame\build\wechatgame`
4. 点击 `导入`

### 3.4 手机预览
1. 微信开发者工具中点击 `预览`
2. 手机微信扫码即可测试

### 3.5 提交审核
1. 微信开发者工具中点击 `上传`
2. 登录小程序后台 > 版本管理
3. 提交审核 → 等待通过 → 发布

## 4. 包体优化

### 4.1 图片优化
- 使用 Cocos Creator 的图片压缩功能
- 水果图片可以适当降低分辨率（100x100足够）
- 使用 SpriteAtlas 合并小图

### 4.2 音效优化
- WAV 文件较大，建议转换为 MP3 或 OGG
- 微信小游戏限制: 单个音频不超过 6KB（超过会自动延迟加载）

### 4.3 代码优化
- 开启代码压缩
- 移除 console.log（生产环境）
- 使用分包加载（如果包体过大）

### 4.4 微信小游戏包体限制
- 主包: 4MB
- 分包: 每个 20MB
- 总计: 不超过 24MB

## 5. 多平台发布策略

### 5.1 开发阶段

## 6. 持续更新流程

1. 修改代码 → Cocos Creator 重新构建
2. Web H5: 刷新浏览器即可
3. 微信小游戏: 重新导入 → 预览 → 上传 → 审核 → 发布

---

## 7. 问题排查

### Q: 构建失败？
A: 检查是否有语法错误，查看 Cocos Creator 控制台日志。

### Q: 微信开发者工具报错？
A: 检查 AppID 是否正确，确保微信开发者工具版本是最新的。

### Q: 手机上显示异常？
A: 检查屏幕适配设置，确保使用 `适配屏幕宽度` 或 `适配屏幕高度`。

### Q: 音效不播放？
A: 微信小游戏需要用户交互后才能播放音频，确保在触摸事件中触发播放。
