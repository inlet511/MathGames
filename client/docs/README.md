# 数一数 — 项目文档索引

## 项目简介

**数一数** 是一款面向 3-6 岁学龄前儿童的数学启蒙游戏。通过快速识别画面中物体数量并选择对应数字，训练儿童的数感和反应速度。

- **引擎**: Cocos Creator 3.8.8
- **平台**: 微信小游戏 / Web H5
- **状态**: 开发中

## 快速开始

### 1. 环境准备
- 安装 [Cocos Creator 3.8.8](https://www.cocos.com/creator)
- 打开项目: `C:\Dev\NumberGame`

### 2. 搭建场景
按照 [场景搭建指南](03-场景搭建指南.md) 创建两个场景:
- `Start.scene` — 启动场景
- `Game.scene` — 游戏主场景

### 3. 测试运行
- 点击 Cocos Creator 播放按钮
- 或参考 [发布部署指南](04-发布部署指南.md) 构建 H5 版本

### 4. 发布
- 选择目标平台（Web H5 / 微信小游戏）
- 按照 [发布部署指南](04-发布部署指南.md) 操作
